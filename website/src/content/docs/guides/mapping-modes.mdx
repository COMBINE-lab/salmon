---
title: Selective alignment & sketch mode
description: How salmon maps reads, and when to use --sketch.
---

salmon has two ways to map reads to the transcriptome. Both produce the
equivalence classes the optimizer needs; they trade accuracy against speed.

## Selective alignment (default)

The default mode. salmon finds maximal exact matches (MEMs) between each read and
the index, chains them with the chaining algorithm introduced in minimap2[^minimap2],
and then computes a fast banded alignment score for each candidate placement using
a native-Rust port of the ksw2[^ksw2] extension aligner, accepting a mapping only
if its score clears a fraction of the perfect score (`--minScoreFraction`, default
`0.65`). This rejects spurious mappings that share k-mers with a transcript but do
not actually align well — the key accuracy advantage of selective alignment[^selalign]
over plain pseudoalignment.

Useful knobs:

- `--minScoreFraction <f>` — acceptance threshold as a fraction of the perfect
  score.
- `--ma / --mp / --go / --ge` — match score, mismatch penalty, gap-open and
  gap-extend penalties.
- `--allowDovetail` — admit dovetailed (short-insert) fragments.
- `--orphanChainSubThresh`, `--postMergeChainSubThresh` — chain-pruning
  thresholds applied before alignment (see the note below).

## Sketch mode (`--sketch`)

Alignment-free pseudoalignment[^kallisto]. salmon maps reads using
k-mer/equivalence-class hits without computing per-placement alignment scores.
This is **faster** and is a good fit when you want throughput and your reference
is high-quality.

Because no per-placement score is computed, sketch mode reports every mapping
for a read as a co-equal best mapping. In `--writeMappings`/`--writeBam` output
the `AS` tag is therefore `0` for all records; a meaningful `AS` requires
selective alignment (see [the pseudoalignment output contract](../../reference/output-formats/#the-pseudoalignment-output-contract)).

```sh
salmon quant -i salmon_index -l A --sketch \
  -1 r1.fq.gz -2 r2.fq.gz -p 16 -o out
```

### Orphan policy

When only one mate of a pair maps, salmon can still record an *orphan* mapping.
Sketch mode defaults to a **relaxed** orphan rule — orphan whenever the other
mate has no consistent target — which tracks selective alignment more closely
and improves agreement with the gold-standard results.

- `--sketchStrictOrphans` switches to the **conservative** rule: only orphan a
  pair when the other mate had *no matching k-mers at all*.

### Dovetail

`--allowDovetail` is honored in sketch mode as well, admitting dovetailed
short-insert fragments.

:::note[Parity with C++ salmon]
2.0 currently defaults `--orphanChainSubThresh` and `--postMergeChainSubThresh`
to `0.0` (align every candidate), which is marginally more sensitive than C++
salmon's `0.95` / `0.9`. Quantification is essentially unaffected
(per-transcript Pearson ≈ 0.999). To reproduce C++ mapping counts exactly, pass
`--orphanChainSubThresh 0.95 --postMergeChainSubThresh 0.9`.
:::
